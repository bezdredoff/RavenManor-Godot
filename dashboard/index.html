FUTURE / CONDITIONAL

Очередь P2 · условия возвращения

P2 не значит «не нужно никогда»: будущие главы, условные пайплайны, явно отложенные функции и обязательные проверки полного сезона имеют разные условия возобновления.

Критический путь: UPDS reuse → карта/предметы → Hall pilot C11 × GFX-11 → главы II–VI → C13 × GFX-13. Утверждённый VN-арт уже в каталоге; Hall map/interaction и device QA по-прежнему отдельные gates.

WORK ITEMS

Все задачи и критерии приёмки

Активные P0/P1 сгруппированы в общие рабочие потоки: один QA/production gate может охватывать несколько задач, не закрывая каждую автоматически. P2 и исторические задачи остаются доступными через «Все задачи».

Смержено = закрыта поставка технической задачи (исключена из оставшейся работы), но не обязательно принята пользователем. При незавершённых тестах и интеграции карточка указывает отдельные следующие задачи. «Принято» — отдельная стадия после подтверждения критериев.

Откройте карточку, чтобы посмотреть результат, зависимости, критерии, evidence и источник. Implementation, QA и художественное утверждение не подменяют друг друга. Статусы обновляются через PR в data/raven/production/production_progress.json.
