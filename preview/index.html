Проверка кандидатных сборок

Эта страница показывает результаты независимых проверок ZIP-патчей. Candidate-код не исполняется на том же домене, что и опубликованная игра. Проверенную Web-сборку можно получить из артефактов GitHub Actions; интерактивный запуск потребует отдельного домена или доверенной среды.

Стабильная версия защищена. Для candidate GitHub Actions выдаются только права чтения исходников. Ни одна candidate-сборка не публикует файлы в корень игры или Service Worker. Доступность артефакта ограничена сроком хранения GitHub.

Как проверить candidate

  1. Откройте нужный запуск GitHub Actions.
  2. Убедитесь, что Godot, Room Builder и Web export прошли успешно.
  3. Загрузите артефакт raven-candidate-web-… со страницы запуска и разверните его в отдельной тестовой среде с другим origin.
  4. Сверьте PR, task IDs, изменения и UX на телефоне. Только после ручного ревью мержите candidate.

Для автоматического запуска интерактивной версии на отдельном origin потребуется дополнительная настройка preview hosting. GitHub Pages не изолирует JavaScript по путям / и /preview/.
