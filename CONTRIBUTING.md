# Contributing

Start by reading `AGENTS.md`, `docs/DECISIONS.md`, and relevant preproduction documents.

Use feature branches and reviewable PRs. Include affected `RM-*` IDs, scope, changed files, exact tests actually run and results, manual checks, save migration, screenshots when map/touch work changes, risks and documentation updates.

Write clean reusable content-driven GDScript. Do not introduce UPDS narrative dependencies, unlicensed content or generated production art. Keep human-readable guides for adding and testing each new component.
