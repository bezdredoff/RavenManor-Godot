# VNS5-07F5 — визуальный таймлайн: вход / ожидание / выход

**Source of truth:** исходное утверждённое HTML-v5 из истории ChatGPT, issue #129. **Статус:** PR_review до независимого CI/Windows native UI QA. Зависит только от уже merged PR #128/130; независим от draft-only Story Map #131.

## Цель и реализация

Вкладка **Animation** (переделанная в PR #128) теперь содержит визуальный редактор FX с **тремя горизонтальными дорожками**:
- **Вход / enter**: синий пресет `fade_in`, start 0ms, duration 650ms, repeat 1, strength 1.
- **Ожидание / idle**: зелёный пресет `breathe`, start 1500ms, duration 1400ms × 3, strength 0.35.
- **Выход / exit**: оранжевый пресет `fade_out`, start 8000ms, duration 650ms, repeat 1, strength 1.

В проекте 20-секундная шкала, tick каждые 5 секунд, playhead. Левый клик по полоске выбирает **конкретный FX cue**, его можно редактировать в уже существующей панели параметры/target/line anchor. Drag клипа по горизонтали сдвигает startMs, с округлением до 50мс, внутри безопасных лимитов. Клик в пустом месте дорожки перемещает scrub. **Play/Pause/Reset** продолжает управлять тем же общим Stage preview; отдельной системы анимаций или gameplay scheduler нет.

Кнопки `+ Вход`, `+ Ожидание`, `+ Выход` добавляют реальные клипы в текущую `stageFxPatches`; у каждого необязательное `phase = enter|idle|exit`. **Старые FX-черновики без `phase` открываются как прежние и не переписываются автоматически**, их классификация в UI по умолчанию idle. Можно менять фазу выбранного клипа в инспекторе. Существующие 32 FX/20с/валидные цели/стабильные ID/undo/line-bound cues/exports и source SHA сохранены. Нельзя удалять actor/prop, на которых висят эти FX.

## Поведение

- Входной `fade_in` на `startMs` плавно показывает sprite; до начала явного enter clip удерживает `alpha=1-strength`. По окончании входа возвращает `alpha=1`.
- Выходной `fade_out` плавно скрывает sprite, **после окончания клипа** удерживает `alpha=1-strength` для честного визуального «выхода». Это касается только **явных** phase presets; старые `fade_in/fade_out` без `phase` имеют ровно прежнюю семантику.
- Эффекты сцены видны на любой реплике; эффекты с `lineId` только на конкретной реплике. Неактивные в текущей реплике полоски приглушены.
- Нет смены поз или анимированных спрайт-кадров, motion paths и ключевых кадров; это **рабочий временной FX-редактор**, не подмена полной character keyframe animation. Качественное моргание требует дополнительных art layers. Не активировать runtime без отдельного продакшен-контракта.

## Native owner QA (Windows Godot 4.7.2)

1. После pull/restart открыть **VN Studio → Raven Manor → Animation**. Убедиться, что видны три дорожки и playhead над реальным Stage.
2. Выбрать background или доступного персонажа, создать `+ Вход`, `+ Ожидание`, `+ Выход`. Проверить три цветные полоски и что кликом можно открыть нужный FX; overlapping выбираются в существующем FX list.
3. Нажать Play, перемотать на 0/325/650/1500/8000/8325/9000 ms. Предпросмотр должен реагировать на выбранный target, у exit после окончания объект остаётся скрытым, Reset снимает визуальное влияние.
4. Перетащить «Выход» с 8000 на ~8500ms; startMs в инспекторе обновляется. Undo возвращает 8000ms. Попробовать слишком позднее время/неверный target; валидатор должен блокировать без потери данных.
5. Привязать один FX к L002. Выбрать L001: полоска приглушена, кадр не меняется от её FX. Вернуться L002; эффект работает.
6. Сохранить `user://` draft, перезапустить Godot, проверить все три clips, phase, startMs, source SHA и Story Map не изменились. Режимы portrait/landscape, ширины 800/1024/1366, scroll до контролов.
7. Провести side-by-side по оригинальному HTML v5 на машине с файлом. Не утверждать полную пиксельную/функциональную паритетность только по этому PR.
