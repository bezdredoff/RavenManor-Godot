# VNS5-07C3 — видимые черновые провода в Story Map

Основание: пользователь после merge PR #125 не смог найти «черновые провода» в VN Studio. **Статус: PR_review до CI и нативной QA.** Не меняет gameplay/runtime.

## Где именно смотреть

1. В Godot открыть **VN Studio → Raven Manor → Director**.
2. Выбрать исходную сцену слева. Справа в инспекторе выбрать вкладку **Story Map** (она соседствует с Stage Inspector / Translations / Asset Library).
3. Сразу под заголовком графа теперь есть **цветная легенда**:
   - **Зелёный провод** — уже существующее каноническое условие (просмотр, не удаляется/редактируется).
   - **Оранжевый провод** — созданный локальный draft (предлагаемая связь, не в игровом runtime).
4. Если для сцены ещё не создано ни одной связи, оранжевого провода **нет**, и Summary явно предлагает: выбрать тип `scene`, целевую сцену, подпись и нажать **«+ Связь»** в блоке **под графом**. Новый провод должен появиться оранжевым. Можно также включить **«Все сцены»** и провести линию от правого **оранжевого** порта исходной сцены к левому оранжевому порту целевой.
5. Клик по оранжевому проводу открывает выбранный draft-edge в существующем инспекторе; если A/B/C накладываются на один провод, по-прежнему показывается выбор стабильного ID. Клик по зелёному не может открыть редактирование, даже если те же два узла имеют параллельный оранжевый draft.

## Реализация

- Два физически различных типа портов `GraphNode`: `port 0` (канон, зелёный) и `port 1` (draft, оранжевый). Для `match3` оранжевый порт только входной. Черновые соединения рендерятся по `1→1`, канонические по `0→0`.
- Редактирование draft из графа строго проверяет реальные `from_port` и `to_port`, поэтому совпадающие endpoints уже не приводят к ошибочному открытию канонической линии.
- Drag-create с зелёных портов отклоняется, и UI объясняет, какие порты использовать.
- Отображение и цвет **не** изменяют `storyGraphPatches`, scene/line IDs, runtime, route gates, сохранения или art approval. No auto-created links or test scene in production.

**Ручная проверка в Godot 4.7.2:**
1. Открыть Story Map на `RM-BEAT-00-01` без черновиков. Убедиться, что канон зелёный, текст «0 оранжевых» и чёткая инструкция «+ Связь».
2. Под графом выбрать `scene`, target `RM-BEAT-00-02`, написать «Тест» и нажать «+ Связь». Оранжевый провод должен появиться с отдельными портами. Если у сцены уже есть безусловная связь, используйте тестовый draft или выберите другой сценарий, не стирая предыдущие данные.
3. Выбрать `choice` A/B/C с checkpoint и соединить оранжевые порты (для выбора сцены включить «Все сцены»); клик по оранжевому проводу показывает конкретную ветку или список A/B/C.
4. Если канон и draft соединяют одни узлы, клик по **зелёному** проводу не должен открывать draft. Сохранение/Undo/Redo/reopen черновика работают как прежде.
5. Проверить 800×640, 1024×640 и 1366×768; убедиться, что легенда/подсказка/кнопка «+ Связь» доступны прокруткой.
