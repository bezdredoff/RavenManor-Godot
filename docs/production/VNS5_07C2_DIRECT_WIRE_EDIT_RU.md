# VNS5-07C2 — выбор связей непосредственно на графе VN Studio

**Основание:** issue #121, merged PR #124 (VNS5-07C1). **Статус:** PR_review — нативная Windows QA владельца не проводилась; CI фиксировать отдельно. Этот этап только для Godot Editor, **не** игровой runtime.

## Задача

После #124 можно создавать draft-связь port-to-port и редактировать её через список под GraphEdit. Пользователь ожидает, что сможет выбрать сам провод на графе и увидеть его свойства. Несколько веток A/B/C могут заканчиваться на одной сцене, из-за чего Godot GraphEdit показывает их как один визуальный провод; редактировать случайную ветку по догадке нельзя.

## Контракт UX

1. На Story Map сначала выберите исходную сцену (один клик по её ноде). **Левый клик по проводу** ищет ближайшее соединение посредством `GraphEdit.get_closest_connection_at_point()`, радиус 12 px в экранных координатах.
2. Если это ровно один draft edge **из текущей сцены**, выбирается именно его стабильный `edge-XXXX`; редактор под графом подставляет kind/target/label, а для choice — lineId и A/B/C. Изменения применяются только через `Сохранить связь` с валидатором.
3. Если в одной визуальной линии два или больше draft edges (например A и C), открывается меню выбора **конкретного ID и подписи**; никакого изменения до явного выбора нет.
4. Если это canonical gate/не редактируемая связка, кнопки сохранения/удаления блокируются, выводится понятное сообщение. Если source принадлежит другой сцене, выводится инструкция сначала выбрать исходную сцену.
5. `Graph.build` добавляет только **ephemeral-поля** `edgeId` и `sourceSceneId` для `kind:draft` в отображаемом графе. В канонический и локальный JSON, runtime/campaign state эти поля не записываются.
6. Выбор сценной ноды переключает Director через deferred-callback, чтобы избежать освобождения GraphNode прямо во время GUI-сигнала.

## Проверки

- `tests/raven/vn_studio_raven_graph_smoke.gd`: соответствие stable ID двум параллельным A/C связям, блокировка чужого source и canonical, открытие именно нужного edge в инспекторе, прежние операции добавления/обновления/удаления, SHA immutability и no-overwrite export.
- CI Godot/Raven/Room Builder/Web/dashboard обязателен. Headless smoke **не доказывает**, что нативный GraphEdit передаст события мыши через `gui_input`; это manual acceptance.
- В Godot 4.7.2: `RM-BEAT-00-01` → сформировать choice A и B к **разным** сценам, затем A/C к **одной** сцене. Клик по первой линии открывает инспектор; клик по общей линии открывает меню двух ID. Выберите C и измените label, убедитесь, что A не изменилась.
- Нажмите каноническую линию gate → scene; редактирование/удаление должно быть отключено. Проверить выбор нод с первого клика, повторное переключение source, drag/zoom/pan.
- Сохранить `user://` draft, перезапустить Editor, повторить выбор; убедиться, что scene/line IDs, A/B/C и SHA канонических каталогов не изменились.
- Размеры: 800×640, 1024×640 и 1366×768. При наложенных проводах/узком viewport проверить, что меню полностью доступно. Текущий инструмент пока не реализует полноценное редактирование/удаление по правому клику на линии; используется существующий inspector.
