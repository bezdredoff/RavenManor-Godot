# VNS5-10 — восстановление работы с Raven-черновиком

**Причина:** после изменения исходных сезонных каталогов (например, импорта EN/BE реплик) `sourceSha256` текущего `user://raven_story_studio/v1/<root-sha>/draft.json` отличается от `main`. Редактор осознанно блокирует черновик, чтобы устаревшие локальные изменения не затёрли канонические. До VNS5-10 интерфейс не давал безопасно выйти из такого состояния.

## Новый путь в Studio

1. Открыть Godot Editor с обновлённым проектом Raven, VN Studio → Raven Manor (по умолчанию). Кнопка **«Архивировать старый черновик и начать новый…»** появляется только при наличии валидного архивируемого JSON и подтверждённого source SHA drift для **того же корня проекта**.
2. Нажать, прочитать причину блокировки и краткую сводку исходных изменений. Подтвердить действие **«Сохранить копию и начать новый»**. **Это не перенос старых правок.**
3. Программа проверяет исходный SHA старого файла, сохраняет неизменённый JSON в `user://raven_story_studio/recovery/<root-sha>/draft-<original-sha>.json`, сверяет **байты** с оригиналом и только после этого создаёт новый пустой черновик, привязанный к текущему `season1_dialogue_catalog`. При неудаче backup операция останавливается, исходный draft не теряется.
4. Редактор снова позволяет добавлять сцену/реплику и нажимать Save. Путь резервной копии показывается под редактором. Чтобы перенести старые изменения, вручную сравнить сохранённые `patches`, `authoredScenes/Lines`, `stagePatches`, `stageV2Patches`, `stageFxPatches`, `storyGraphPatches` и `promotionSceneIdMap` с актуальным каноном; автоматической операции rebase нет.

**Если старые правки нужны немедленно:** сначала скопировать `user://` JSON вне Godot; не стирать/не переименовывать его без резервной копии. Новый инструмент хранит точную копию и не применяет её в `res://` или игровые сейвы.

## UPDS — отдельно

Рабочее место по умолчанию — **Raven Manor**. Левый legacy-навигатор, верхний UPDS toolbar, UPDS dialogs/graphs и лишние вкладки скрыты. Кнопка **«Инструменты UPDS…»** отдельно открывает донорский инструмент; кнопка **«← Raven Manor»** возвращает в сценарий игры. UPDS integration and conversion are preserved, but optional.

## Приёмка владельцем

- После merge и свежего импорта проекта в Godot 4.7.2 проверить заблокированный черновик. Нажать **Архивировать…**, убедиться в предупреждении, сохранить копию, создать тестовую реплику, сохранить и перезапустить Godot.
- В проводнике открыть путь `recovery`, убедиться, что старые правки существуют, не были подмешаны в новую версию, и не изменился исходный production JSON.
- Без подключения локальной папки UPDS проверить, что слева видны сцены Raven и Stage, верхние инструменты UPDS не показаны. Кнопкой **Инструменты UPDS…** открыть старый донорский режим и вернуться.
- Если видны `Unexpected NUL character` в локальном Godot логе, собрать **полный путь файла и первую ошибку стека**: сами скриншоты не доказывают, что это связано с draft SHA. CI может быть зелёным, даже если локальная установка имеет неподдерживаемый файл/кэш.

**Безопасность:** это не массовый автоматический rebase и не способ обходить review/promotion/canonical hash gate. Существующие live game content, saves, assets and locale untouched.
