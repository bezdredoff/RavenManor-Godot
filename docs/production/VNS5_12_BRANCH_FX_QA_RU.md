# VNS5-12 — три варианта выбора и микро-FX, только в черновике

После merge **VNS5-11** и этого PR открой Godot 4.7.2 → VN Studio → Raven Manor → **Дополнительно…** → **QA · выбор 3 героев + FX**. Подтверди. В конец текущего draft добавятся 4 сцены после уже существующих новых сцен. Исходные 28 сцен и 280 реплик не меняются.

Первая новая сцена `QA · выбор героя (черновик)` включает авторский текст с выбором, затем реплики Эвелин, Ады и Роуэна. Stage автоматически показывает их на BG-HALL (реально существующий утверждённый вариант), в трёхместном шаблоне. На одной и той же первой реплике Story Map есть три **оранжевых** choice-провода: A → Эвелин, B → Ада, C → Роуэн. В каждой из трёх новых сцен отдельная **оранжевая** обратная связь `scene → выбор`. Канонические зелёные провода не меняются, QA-сцены не соединены с игровым runtime.

Во вкладке Animation для общего кадра: **Эвелин — fade_in/enter, Ада — breathe/idle, Роуэн — shake/idle**. В личных сценах соответствующий FX привязан к одному персонажу. Это существующие bounded preview-FX, не новые арт-файлы или анимационный scheduler; `blink` остаётся proxy. Выбор активен только в редакторе; в самой игре его пока нельзя кликать как реальный runtime-переход.

Проверь Story Map в режиме «Все сцены», щёлкни три оранжевые связи, открой каждую новую сцену и убедись в обратном проводе. В Animation проверь Play/Pause и scrub до 0–5 с, отличимые fade/breathe/shake. Сделай Undo один раз — все четыре QA-сцены и их FX исчезнут; Redo вернёт. Только при необходимости нажми **Сохранить Raven-черновик**. Другие изменения локального черновика не перезаписываются. При повторном нажатии кнопка откажет, если QA-демо уже присутствует.

Связанный тест: `tests/raven/vn_studio_branch_demo_smoke.gd` (валидирует 3 choice + 3 возврата, cast images, FX, undo, сохранность исходников). Текущие артовые approvals, история, locale/Match-3 и saves не меняются.
