## Canonical bindings (no new runtime path logic)

`vn_staging.json` already maps all scene IDs and exact three-part tuples. `raven_vn_backgrounds.gd` loads the catalog for both the existing gameplay `raven_vn_game_view.gd` and native VN Studio stage; Proto Lab Gallery uses the same registered assets. This patch only adds the WebP textures to `assets/raven/vn_backgrounds/`, adds six catalog entries and updates headless smoke tests; it **does not modify** scene data or saves.

The Bath is a **vignette**, not a new traversable room. The Garden plate supports the authored Chapter IV VN scene; it is **not** a replacement for the whole hub map, Room Builder geometry or collision.
