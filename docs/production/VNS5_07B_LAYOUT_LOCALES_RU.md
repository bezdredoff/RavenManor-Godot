# VNS5-07B — постоянный Stage и три локали

Основание: issue #121 после merged PR #122. Сравнение структуры сделано с локальным HTML-прототипом `C:/git/Raven_VN_Studio_Godot_Handoff_v5_2026-11-01/prototype/raven_vn_studio_v5.html`, заметками `raven_vn_studio_v5_authoring_notes.md` и `docs/02_PRODUCT_UX_AND_WORKFLOWS.md`. Это нативный Godot UI, не перенос HTML/CSS; точное пиксельное совпадение не заявлено.

Режиссёр: слева список сцен и список реплик, в центре постоянно видимая постановка, справа Stage Inspector и вкладки Translations, Asset Library, Story Map, Animation, Promotion Review. Три разделителя изменяют ширину колонок; ширины хранятся в пользовательских EditorSettings. Списки сцен и реплик можно свернуть. Экспортные действия открываются кнопкой `Экспорт…`, сохранение черновика и Undo/Redo доступны в верхней строке. Логический VN кадр остаётся 390×844 и прокручивается в ограниченном окне, без изменения runtime масштаба.

В Translations одновременно видны RU, BE и EN. Пустой BE/EN перевод остаётся пустым и явно помечен `Не переведено · RU fallback`; редактор не сохраняет fallback как перевод. Для draft-сцены редактируются три названия; канонические названия доступны только для чтения. Переключатель RU/BE/EN меняет язык preview и подписей, сохраняя текущий lineId. Вкладки inspector тоже не сбрасывают выбор. Данные по-прежнему идут в прежний локальный `user://` draft; схема не меняется.

## Ручная проверка

1. В Godot 4.7.2 открыть Raven Manor → Director. При 800×640, 1024×640 и 1366×768 убедиться, что Stage виден сразу, списки слева, Inspector справа; проверить три разделителя, горизонтальный и вертикальный scroll, сворачивание/возврат списков.
2. Выбрать существующую сцену и реплику L002. Переключить RU→BE→EN и вкладки Inspector; lineId остаётся L002, Stage не исчезает.
3. В новой draft-сцене заполнить RU/BE/EN тексты и названия, затем очистить BE; поле должно показывать `Не переведено`, а preview использовать RU fallback без записи копии RU в BE.
4. Сохранить draft, закрыть и снова открыть Godot; сверить выбранные тексты/названия и отсутствие перевода. Изменить поле, проверить Undo/Redo и повторное сохранение.
5. Проверить длинную реплику, доступность всех трёх полей через scroll, Stage Inspector для фона и двух персонажей; убедиться, что игровые сейвы, канон и art approval не изменились.

Автоматические проверки: `tests/raven/vn_studio_layout_smoke.gd`, `tests/raven/vn_studio_new_scenes_lines_smoke.gd`, существующие `scripts/check.sh`, dashboard validator. Headless UI smoke не заменяет native mouse/visual QA. Rollback: закрыть PR; сохранённый `user://` draft использует прежнюю схему и остаётся совместимым с VNS5-07A.
