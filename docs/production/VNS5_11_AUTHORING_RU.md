# VNS5-11 · авторские реплики, портреты и drag-and-drop

- После создания Raven draft-сцены с обычным персонажем редактор подставляет утверждённый базовый вариант из `vn_character_catalog.json` (предпочтение neutral). Если точного изображения нет, используется корректный placeholder `ART PENDING` — никаких выдуманных asset IDs.
- Первая реплика создаёт одного персонажа в центре; новая реплика **другого персонажа** автоматически добавляет его и применяет шаблон 2 или 3 портретов. Повторная реплика существующего персонажа не дублирует его. Четвёртый не добавляется в Stage автоматически — это ограничение кадра, но текст остаётся в черновике. Добавление нового актёра перебалансирует координаты; в дальнейшем их можно уточнять вручную.
- В списке говорящих есть **«Авторский текст (без персонажа)»**. В черновике создаётся `speakerId: RM-NARRATOR`, `delivery: narration`. Это **не** одобренный production actor/cue: публичный narrative runtime ещё не поддерживает такой ID и будет требовать независимого review-контракта при promotion. Не подменяет narrator Эвелин.
- Drag & drop из списка реплик на другую реплику меняет порядок **только** новых authored lines **в одной сцене**. Canonical lines перемещать нельзя. Это одна Undo-операция и она сохраняет стабильные line IDs, RU/EN/BE, choice checkpoints и line FX.
- Локальный `user://` draft и SHA-гейты остаются прежними. Никаких новых runtime веток, save migration или новых изображений.
- Ручная проверка после merge: создай отдельную тестовую сцену с Эвелин, добавь Аду и Роуэна, проверь 1/2/3 и видимые изображения; затем авторский текст, отсутствие четвёртого портрета, перетаскивание 3→1, Undo/Redo, сохранение/перезапуск Godot.
