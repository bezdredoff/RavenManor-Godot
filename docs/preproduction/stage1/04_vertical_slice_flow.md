# Raven Manor — 04 Early vertical slice flow — Stage 1 v0.5 (approved)

**Scope:** один непрерывный фрагмент `RM-CH-01`, вход/холл + спальня и компактный санузел (санузел — смежная функциональная ячейка, а не вторая самостоятельная master-локация). Один проверяемый дверной переход `RM-DOOR-HALL-BEDROOM`. `RM-DOOR-HALL-PARLOR` сохранён как зарезервированный legacy-ID и не используется в S1. Все пять `RM-BEAT-01-01`–`RM-BEAT-01-05` сохранены.

## Драматическая мини-дуга
Эвелин приезжает только на несколько дней. Вежливые Лукас и Ада выглядят обычными людьми, лишь слегка странными. Дом негостеприимен прежде всего **практически**: пыль, нет постели и работающей ванной. Эвелин решает обустроить минимум для проживания, обнаруживает знакомую детскую вещь, принимает помощь местного мастера и проводит первую ночь. **Малое завершение:** «я здесь действительно могу остаться». **Cliffhanger:** знакомая детская мелодия, которую никто не включал; никаких явных призраков/вампиров пока нет.

## Five hotspots (IDs сохранены, назначение версии изменено до канонизации)
| hotspot_id | Вид | Действие и сюжетный результат | Gate |
|---|---|---|---|
| `RM-HS-001` | inspection/dialogue | Домашний список необходимого, предремонтный диалог с Адой; спальня и санузел непригодны | открывает `RM-LVL-001` |
| `RM-HS-002` | restoration | Подготовить спальню: убрать коробки, отмыть, раскрыть мебель, застелить кровать → `RM-REST-001`; детская вещь/зарубка | `RM-LVL-001` first clear |
| `RM-HS-003` | restoration | Очистить санузел, разобрать детали, затем **мастер чинит сантехнику** → `RM-REST-002`; изменённое помещение | `RM-LVL-002` и `RM-LVL-003` first clear + мастер |
| `RM-HS-004` | clue/dialogue | Детская вещь, разговор с Адой **после восстановления**; Ада кажется слишком осведомлённой | `RM-REST-001`, `RM-REST-002` saved |
| `RM-HS-005` | door | Первая проверка перемещения персонажа через `RM-DOOR-HALL-BEDROOM`, с корректным закрытием/открытием | rest states saved + `RM-HS-004` |

| Seq | Действие | На экране / в сюжете |
|---|---|---|

| `RM-VS-02` | `RM-LVL-001`: «Разобрать спальню» | Match-3 сортировка вещей / clearing blockers; награда подготовки работ |
| `RM-VS-03` | `RM-REST-001` в спальне | Эвелин убирает сама, меняется крупный силуэт кровати и свободная площадь; впервые замечает детскую отметку |
| `RM-VS-04` | `RM-LVL-002`: «Разобрать сантехнический шкаф» | поиск нужных деталей/очистка в существующих match-3 правилах |
| `RM-VS-05` | `RM-LVL-003`: «Подготовить ванную к ремонту» | освобождение прохода/сортировка принадлежностей; достижения складываются в work_points |
| `RM-VS-06` | `RM-REST-002`: приглашённый мастер чинит сантехнику | короткий звонок/визит в VN или offscreen звуки, но не магическое самостоятельное починение; состояние ванной меняется |
| `RM-VS-07` | `RM-HS-004`: осмотр детской вещи и постремонтный диалог | подтверждение, что Эвелин действительно жила в доме; Ада избегает прямого ответа на очень старое воспоминание |
| `RM-VS-08` | `RM-HS-005`: дверь спальни открывается, Эвелин проходит в комнату | тест навигации, door gate, occlusion; комната пригодна для сна |
| `RM-VS-09` | Первая ночь / доставка еды у двери / тихий звук знакомой мелодии | маленькая завершённая арка + cliffhanger без раскрытия монстров |

**Один переход:** hall → bedroom. Санузел представлен соседним функциональным пространством без отдельного анимированного дверного прохода в slice; его более подробная навигация оставлена на этап 2.

## Ресурсный контракт — только сюжетный, без stage-2 экономики
Три последовательных first-clear Match-3 дают `work_points`, которых достаточно для двух обязательных реставраций; второй ремонт **дополнительно** требует присутствия специалиста. Это не выдача денег из воздуха. Повторное прохождение уровня после победы не даёт повторную первую награду. Баланс, условия и persistence — в этапе 2.

**Выбор:** после входа можно осмотреть объекты в любом порядке; обязательная цепочка «спальня → санузел → первая ночь» линейна в вертикальном срезе, чтобы проверить обе роли ремонта. В полном сезоне небольшая косметика и необязательные задачи могут открываться параллельно. Условие «несколько побед подряд без провала» не делаем обязательным: оно может наказать игрока отказом в доступе к основному сюжету.

## Shot and asset risks
- Два заметных state changes: спальня (вид кровати и прохода), ванная (водопроводные элементы + свет).
- 5 hotspots, 3 match-3, 2 restoration, 1 door gate, 1 physical clue, pre/post dialogue, completed first-night mini-arc, cliffhanger.
- Главные VN-участники: Эвелин и Ада; Лукас в коротком прологе, сантехник — offscreen или 1 статичное cameo. Избегать сложной анимации рук с инструментами.
- Открытого сверхъестественного в slice **нет**; только 2–3 маленьких странности для повторного прочтения. Проверка reveal Ады вынесена в главу 2.
- В full map дверь спальни может быть видна, но не проходится, пока не подтверждено восстановление; план door state machine — в этапе 2.

## Самопроверка по хэндоверу
| Критерий | Оценка |
|---|---|
| Сезон имеет тайну и финал | PASS на уровне предложения: в `01`, `02`; мотивы прежнего хранителя требуют редактуры |
| Каждая глава связана с местом и реставрацией | PASS: жилые зоны → социальные зоны → кухня → оранжерея → часы → встречи |
| Каждый beat функционален | PASS на уровне 24 строк в `03`, после проверки дублирования |
| Vertical slice непрерывен | PASS: 5 hotspots, 3 последовательных уровня, 2 реставрации, 1 дверь, улика, pre/post, мини-арка, cliffhanger |
| Первичный список assets и рисков | PASS: 5 master + 1 micro-bath (and low-cost exterior threshold); 4 main characters; новое бремя specialist cameo/ремонтных состояний явно выделено |

**Финальное утверждение scope:** шесть игровых помещений (5 master + 1 micro-set), внешняя входная точка без отдельного master; неисправная электропроводка вне жилого сектора объясняет закрытые крылья. **Открыты для последующей художественной полировки:** кто инициировал наследственную процедуру именно сейчас, точные мотивы старой семейной ссоры, постановка первого доброжелательного reveal Ады. **Этап 1 утверждён; этап 2 не начат.**
