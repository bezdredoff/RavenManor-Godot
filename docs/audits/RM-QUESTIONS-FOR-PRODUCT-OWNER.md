# Raven Manor — вопросы владельцу продукта

Только вопросы, которые нельзя решить аудитом кода.

1. Остаётся ли утверждённым искусственный Stage-1 gate: спальня подготавливается через corridor cutaway, но физически открывается только после ремонта ванной и записи улики? Это технически реализуемо, однако может восприниматься нелогично.
2. Должен ли игрок свободно тапать по любой walkable точке или выбирать только hotspots/anchors? Решение определит `NavigationRegion2D` против преимущественно `AStar2D` graph.
3. Дверь спальни должна визуально открываться/закрываться каждый проход или после первого открытия оставаться открытой в рамках сессии?
4. Нужна ли Bathroom как полноценное walkable помещение в первом vertical slice, или утверждённый corridor-side work vignette остаётся достаточным?
5. Какой asset считается каноническим identity reference Эвелин для будущего map-animation pilot? Ранее созданный `evelyn_neutral_00001_.png` явно отвергнут.
6. Публикация reusable toolkit планируется сначала как MIT open-source addon или как потенциальный коммерческий Asset Store продукт? Это влияет на dependency/license policy до начала выделения API.
