 # VN Studio — native Godot EditorPlugin
 
+## VNS5-05A — editor-only сценный таймлайн микроанимаций (implementation candidate)
+
+`Raven Manor → Director → Постановка → Микроанимации (FX draft)` предлагает отдельный список FX-событий на уровне сцены. Цель выбирается **только из текущей сцены** (фон, один из 1–3 актёров, существующий prop instance). Доступны `breathe`, `blink`, `shake`, `pulse`, `fade_in` и `fade_out`; задаются `startMs` (0–15000), `durationMs` (120–4000), `repeat` (1–5), `intensity` (0–1). Не более 32 событий и 20 секунд на сцену. Встроенный ползунок времени и Play/Pause показывают deterministic editor proxy (blink — краткое вертикальное сжатие, а не новая нарисованная эмоция), FX Undo ограничен 32 шагами. Меняется только отрисовка редактора, не байты изображений.
+
+События сохраняются отдельно в `raven-vn-studio-draft-v1.stageFxPatches[sceneId]`, тип `raven-vn-stage-fx-v1`; старые черновики без FX остаются валидны. Цели проверяются против существующих stage-v1 актёров и stage-v2 props; удаление используемой цели блокируется. В `Экспорт FX review` входят текущие stage v1/v2 patches, FX cues и SHA исходников; результат пишется по hash-based имени в `user://raven_story_studio/fx/exports`, **никогда не перезаписывается**. Отдельные v1/v2 exports откажутся от FX, а не потеряют таймлайн. Эффекты **не исполняются в игровом VN**, не добавляют sprites/keyframes, не мигрируют `vn_staging.json`, не меняют `res://`, save или UPDS. Animation compositor, line-specific triggers, art assets и production promotion — отдельный gate. Подробные проверки: `docs/production/VNS5_05A_MICRO_FX_RU.md` и `tests/raven/vn_studio_stage_fx_smoke.gd`. Godot CI и ручная QA обязательны; без них не считать задачу принятой.

+## additive offset, scale factor and opacity factor for a single cue.
+static func sample(cue: Dictionary, elapsed_ms: int) -> Dictionary:
+	var neutral := {"offset": Vector2.ZERO, "scale": Vector2.ONE, "alpha": 1.0}
+	var start: int = int(cue.get("startMs", 0))
+	var duration: int = int(cue.get("durationMs", 1000))

+	if duration <= 0 or repeat_count <= 0 or elapsed_ms < start or elapsed_ms >= start + duration * repeat_count:

+	var strength: float = clampf(float(cue.get("intensity", 0.0)), 0.0, 1.0)
+	var wave: float = sin(PI * 2.0 * phase)

+			neutral["scale"] = Vector2(1.0, 1.0 - 0.09 * strength * close)
+		"shake":
+			neutral["offset"] = Vector2(5.0 * strength * wave, 1.7 * strength * sin(PI * 6.0 * phase))
+		"pulse":
+			var pulse: float = 1.0 - cos(PI * 2.0 * phase)
+			neutral["scale"] = Vector2.ONE * (1.0 + 0.06 * strength * pulse)
+		"fade_in":
+			neutral["alpha"] = lerpf(1.0 - strength, 1.0, phase)
+		"fade_out":
+			neutral["alpha"] = lerpf(1.0, 1.0 - strength, phase)
+	return neutral

+# VNS5-05A — сценный редактор микроанимаций VN Studio
+
+**Baseline:** RavenManor-Godot `main@7652a20676bce76e7aead065bdd025b8cee5154b` после PR #104 и #103. **Status:** implementation candidate; Godot CI и manual Editor QA не выполнены на этой ветке. Scope: P0 editor-only stage micro-FX timeline; runtime playback и line-level cue triggers остаются отдельной задачей VNS5-05B.
+
+## Контракт
+
+- Существующий `raven-vn-studio-draft-v1` расширен необязательным `stageFxPatches[sceneId]`. Старые черновики без этого поля валидны, автоматически не переписываются. Патч: `{format:"raven-vn-stage-fx-v1",schemaVersion:1,sceneId,cues:[...]}`.
+- Cue: `{id:"fx-0001",targetType:"background|actor|prop",targetId,effect,startMs,durationMs,repeat,intensity}`. Цели: `background`, текущие `RM-CHAR-*` или текущие `prop-####` из Stage v2; никаких произвольных путей или ресурсов.
+- Effects: `breathe`, `blink` (только геометрический proxy, не новый портрет), `shake`, `pulse`, `fade_in`, `fade_out`. `startMs` 0..15000, `durationMs` 120..4000, `repeat` 1..5, `intensity` 0..1; суммарный конец до 20000 ms; максимум 32 cues.
+- Семплирование `StageFx.sample(cue,elapsedMs)` **чистое**, независимо от FPS и истории кадров; каждый update возвращает scale/offset/alpha после сброса editor controls к исходной раскладке. 32 шага локального Undo; в глобальном Raven draft — обычный undo/redo snapshot.
+- Сохранение via `Store.set_stage_fx` с source SHA locks на staging/cast; old draft remains valid. Невозможно удалить v1 актёра или v2 prop, если на него ссылается FX. Патч v2 и FX не применяется к runtime автоматически.
+- `Store.export_fx_candidate` создаёт hash-based no-overwrite `user://raven_story_studio/fx/exports` JSON со stage v1 patches, v2 patches, FX, pinned source SHA, `runtimeApplied:false`. v1 stage и v2 stage exports **отклоняются** при FX, чтобы не терять данные тихо. Это НЕ публикация в production.

+func _run() -> void:
+	var root_path: String = ProjectSettings.globalize_path("res://")
+	var staging_path: String = root_path.path_join(Store.STAGING)
+	var source_path: String = root_path.path_join(Store.RELATIVE)
+	var staging_sha: String = FileAccess.get_sha256(staging_path)
+	var source_sha: String = FileAccess.get_sha256(source_path)
+	var project: Dictionary = Store.open_project(root_path)
+	assert(project.get("ok", false), str(project.get("error", "")))
+	var scene_id: String = str(project["shots"].keys()[0])
+	var draft: Dictionary = Store.fresh(project)
+	draft.erase("stageFxPatches") # existing saved v1/v2 Raven drafts stay valid
+	assert(Store.validate(project, draft).is_empty())
+	var stage: Dictionary = Store.effective_stage(project, draft, scene_id)
+	var v2: Dictionary = StageV2.fresh(scene_id)
+	var fx: Dictionary = StageFx.fresh(scene_id)
+	assert(StageFx.validate(stage, v2, fx).is_empty())

+	fx["cues"][0]["effect"] = "pulse"
+	fx["cues"][0]["startMs"] = 250
+	fx["cues"][0]["durationMs"] = 500
+	fx["cues"][0]["repeat"] = 2

+	assert(StageFx.sample(fx["cues"][0], 500)["scale"].x > 1.0)

+	invalid = fx.duplicate(true)

+	invalid = fx.duplicate(true)
