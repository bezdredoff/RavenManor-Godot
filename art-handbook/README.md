# Raven Art Production Handbook

Задачи GFX-05-04 / GFX-05-05. Откройте `index.html` двойным щелчком или `/art-handbook/` на сайте после публикации. JavaScript работает локально без сервера; исходные изображения находятся рядом в репозитории, а в скачиваемом ZIP есть автономные превью.

Книга связывает 62 принятых VN-кадра персонажей, 26 зарегистрированных VN-фонов, 13 ранних/технических raster-файлов и 52 внешних wall-candidate результата с 64 рецептами и источниками. Статусы архива не меняются от включения в документацию. Все 101 raster-файл `assets/` покрыт, включая placeholders; SVG/производные инструменты Builder описаны ссылками на их кодовые pipelines.

Первичные данные: `data/raven/production/art_workflow_handbook.json`, `content.json`, зафиксированные `files/`. `catalog.json` и `data.js` генерируются из них. Краткие настройки нужно читать вместе с полным состоянием узла: stored defaults не обязательно активны. Подробный контракт — `files/AGENT_GUIDE.md`.

```powershell
python scripts/raven/tools/build_art_handbook.py --write --make-download
python scripts/raven/tools/build_art_handbook.py --check
python scripts/raven/tools/build_art_handbook.py --bundle-to build/web/art-handbook
```

`--write` пересобирает страницу из сохранённых данных, не обращаясь к ComfyUI или моделям. `--check` проверяет покрытие репозиторных изображений, связи и SHA. Снимок окружения не снимается заново на CI. Новый PNG/WebP/JPG в `assets/` требует новой записи о происхождении/рецепте или явного статуса неизвестности.

`--bundle-to` готовит сайт и скачиваемый ZIP, копирует опубликованные полные изображения рядом с HTML, потому что браузерная страница не может читать текстуры из Godot PCK. `art-handbook/` исключён из импорта/экспорта Godot. Сгенерированные ZIP не хранятся в Git.

Пакет `downloads/workflow-pack.zip` содержит страницу, previews, machine catalog, флоу, настройки, prompts, входы/маски, локальные helper scripts и лицензии. Полные модели и приватная базовая VNCCS-библиотека не включены. Полные игровые WebP доступны в самом репозитории и через ссылки страницы.

API/UI исторических запусков отделены от подготовленных replay-копий. 34 inpaint-рецепта имеют Replay UI с теми же входами/выходами, что и Replay API. Для четырёх поз replay API использует сохранённый манекен вместо browser capture. Replay не исполнялся на GPU при создании этой книги; preflight, ссылки, файлы и восстановление защищённых пикселей проверяются отдельно.

Проверки: `test_art_handbook.py`, `tests/browser_smoke.html`, стандартный проектный CI. Успешные browser-тесты не являются художественным приёмочным решением или physical-device QA. Verbatim ChatGPT prompts и внутренние генерационные параметры не записаны в доступном корпусе; они оставлены неизвестными, а не реконструированы задним числом.
